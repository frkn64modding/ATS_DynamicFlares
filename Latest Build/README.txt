INSTALLATION
━━━━━━━━━━━━━━━━━━━━━━━

1. Extract the archive to any folder on your computer.
2. Run the EXE installer.
3. Click "Sign In with Modsy". When your browser opens, approve the login request.
4. Click "Install Dynamic Flares". That's all!
5. Launch American Truck Simulator.
6. Open Mod Manager.
7. Activate Dynamic Flares.

Note: The installer will automatically detect your American Truck Simulator mod folder. If it cannot be detected, simply select your Documents\American Truck Simulator\mod folder manually.

━━━━━━━━━━━━━━━━━━━━━━━
IMPORTANT
━━━━━━━━━━━━━━━━━━━━━━━

- American Truck Simulator must be installed before running the installer.
- Place Dynamic Flares above any flare, lighting, or graphics mod in Mod Manager for best results.

FAQ
━━━━━━━━━━━━━━━━━━━━━━━

Why is Dynamic Flares installed using an EXE instead of a .scs file?

Dynamic Flares includes an installer to simplify setup and ensure all required settings are configured automatically. The installer only installs the mod and applies the required game configuration changes for the mod to function correctly.
